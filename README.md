# AnimeFetcher
Das ist mein persönlicher Wrapper der Jikan Api, welche Daten zu der Internetseite MAL bereitstellt.

Das ganze ist noch in Arbeit und dient vor allem meinen eigenen Lernzwecken.

Es handelt sich hier um ein IntelliJ Projekt.
Bei Bedarf können die Klassen auch einfach rauskopiert werden.
Alles basiert ausschließlich auf Java.
